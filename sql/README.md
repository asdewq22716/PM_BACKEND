# 🗄️ SQL Schema & Scripts Directory

โฟลเดอร์นี้ใช้สำหรับเก็บไฟล์โครงสร้างตาราง (Table Schema), DDL Scripts, Migration และ Seed Data ของโปรเจกต์ PM_BACKEND เพื่อให้อ่านและอ้างอิงโครงสร้าง Database ได้ง่ายและเป็นระเบียบ

### โครงสร้างไฟล์แนะนำ:
- `schema.sql` หรือ `<feature_name>.sql`: ไฟล์ Create Table / DDL ของแต่ละโมดูล
- `seeds.sql`: ข้อมูลเริ่มต้นสำหรับการทดสอบระบบ
